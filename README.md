## 📋 Descripción del proyecto

Análisis de contexto y stakeholders para determinar si existe un problema 
real que justifique el desarrollo de un sistema de información para la 
gestión de préstamo y devolución de equipos tecnológicos (computadores 
portátiles, tabletas, proyectores) en una institución educativa.

## ❓ Problema analizado

> La institución educativa carece de un canal formal único y de una fuente 
> única de verdad para la custodia de los equipos tecnológicos. Esto obliga 
> a usuarios y personal a improvisar "sistemas de sombra" (correos 
> informales, acuerdos verbales y hojas de cálculo locales paralelas) que 
> fragmentan la información, impiden la trazabilidad en tiempo real y 
> generan falsa escasez, fricción operativa y decisiones de compra sin 
> datos confiables.

**Tipo de problema:** Combinación de **Información + Proceso + Comunicación**.

**Stakeholder principal afectado:** Estudiantes solicitantes.

---

## 🎯 Decisión final del squad

Después de aplicar los 3 ciclos de IA (Generar → Criticar → Decidir) y 
contrastar con evidencia del caso, el squad concluye que:

1. **Sí existe un problema** que justifica el desarrollo del sistema.
2. El problema **NO es de inventario** (hay equipos), sino de **información 
   desfragmentada, proceso sin protocolo y comunicación asimétrica**.
3. La solución debe priorizar una **Single Source of Truth** con trazabilidad 
   en tiempo real, no una app móvil ni un módulo de sanciones.
4. La **Restricción 2** (asimetría de interés del personal) es una dimensión 
   crítica que ningún sistema técnico resuelve por sí solo.
